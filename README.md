# Prity Kumari — Professional Portfolio

A responsive, single-page developer portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Download and unzip the project.
2. Open `index.html` in a browser. No build tools are required.

## Deploy with GitHub Pages
1. Create a GitHub repository (for example, `prity-portfolio`).
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under build and deployment, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for deployment and open the published URL shown on the Pages settings screen.

The contact form uses `mailto:` and opens the visitor's configured email app; it does not send or store messages on a server.
